# Inventory Portal

This compact Node.js repository is included so DepGuard AI can be shown with a consistent, importable project.

To import it locally, set `LOCAL_REPOSITORY_ROOT=C:\Downloads\prj4` in `backend/.env`, restart the backend, then use **Local Repository Path** and enter this folder's absolute path.

The project has a small npm dependency inventory so scans can populate the dependency tree, SBOM, advisory, audit, and network-activity views.
